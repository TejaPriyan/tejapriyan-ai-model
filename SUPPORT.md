# Support

Need help with Tejapriyan AI? Here is the fastest route.

## 1. Check the README first

The [README](README.md) covers installation and has a
[Troubleshooting section](README.md#troubleshooting) for the most common
problems:

- the site not detecting your local Ollama (`OLLAMA_ORIGINS`)
- `model 'tejapriyan' not found`
- slow answers
- expired Cloudflare tunnel URLs
- the SQL sandbox failing to load

## 2. Search existing issues

Someone may have hit the same thing already:
[open and closed issues](https://github.com/TejaPriyan/tejapriyan-ai-model/issues?q=is%3Aissue).

## 3. Open an issue

- ❓ **Question / help** — [Q&A template](https://github.com/TejaPriyan/tejapriyan-ai-model/issues/new?template=question.yml)
- 🐛 **Something is broken** — [Bug report](https://github.com/TejaPriyan/tejapriyan-ai-model/issues/new?template=bug_report.yml)
- 💡 **Idea for an improvement** — [Feature request](https://github.com/TejaPriyan/tejapriyan-ai-model/issues/new?template=feature_request.yml)
- 🔒 **Security problem** — do not post publicly; follow [SECURITY.md](SECURITY.md)

This is a personal project maintained in spare time, so replies are best-effort.
Clear reproduction steps make a fast answer far more likely.
